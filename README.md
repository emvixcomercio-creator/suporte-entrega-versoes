# Suporte Entrega para Windows

Instaladores do programa Suporte Entrega, da Emvix Comércio Ltda (CNPJ 61.960.216/0001-93).

Para instalar, baixe o arquivo `SuporteEntrega-Instalar` da versão mais nova, na seção **Releases** ao lado. Depois de instalado, o programa se atualiza sozinho.

O programa funciona com a licença do Suporte Entrega (7 dias grátis pelo e-mail da loja). Site: https://emvixcomercio-creator.github.io/suporte-entrega/

Sem relação oficial com o Zé Delivery, a Ambev, o WhatsApp ou a Meta.
